# IoT Simulation Dashboard

Frontend for an IoT device simulation and monitoring app. Built with React, TypeScript, Vite, and Tailwind CSS.

## Features

- Device management and live monitoring
- Alerts and simulation controls
- Dashboard with charts and activity feed
- Auth flow (login, register, OTP) with mock data

## Getting started

```bash
npm install
npm run dev
```

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start dev server |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |
| `npm run lint` | Run ESLint |

## Stack

React · TypeScript · Vite · Tailwind CSS · Zustand · Recharts · React Router
